PaperStamp — Protocol Exerciser

Every host→plugin message has a button. Every plugin→host message appears in the log below. The right pane is the live plugin iframe.

Controls

Lifecycle

Basic wiring. Ping shows the plugin is alive; register saves a named layout; export returns the current in-memory layout.

Layouts (saved in plugin localStorage)

The dropdown is populated from onReady.layouts and refreshed by listLayoutDefs. previewById renders a saved layout without printing. printById prints it.

Designer

Opens the full designer UI inside the embedded iframe. Same designer as index.html. Saves go to the plugin origin's localStorage.

Print & preview (current in-memory layout)

Uses the layoutDef currently loaded in the plugin. After import or previewById, this is that layout.

Import / export file

JSON file containing a layoutDef. Round-trips a layout through the host filesystem.

Field values (auto-generated from current layout)

Each input maps to an item whose name matches. Values are sent as fieldValues on preview/print calls.

Load a layout to see its fields.

Protocol reference (expand to see JSON shapes)

paperstamp:ready — emitted on load, after register, and in reply to ping 
{ type:'paperstamp:ready', version:'1', layouts:['id1','id2'], layoutDefs:{ id1:{...}, id2:{...} } }

Host receives this once on boot, again after register, and again after ping. Tolerate repeats.

paperstamp:preview — render a layoutDef without printing 
{ type:'paperstamp:preview', layoutDef:{...}, fieldValues:{ name:'Jane' } }

Requires layoutDef.items to be an array. Renders silently. No print dialog.

paperstamp:previewById — render a SAVED layout by id, no printing 
{ type:'paperstamp:previewById', layoutId:'shipping-label', fieldValues:{ name:'Jane' } }

New in this version. Loads the layout from plugin localStorage, renders it, does not print.

paperstamp:print — print an arbitrary layoutDef (stateless) 
{ type:'paperstamp:print', layoutDef:{...}, fieldValues:{...}, options:{ persist:false } }

Opens the browser print dialog. Nothing persisted unless layoutDef.name is set AND options.persist is true.

paperstamp:printById — print a SAVED layout by id 
{ type:'paperstamp:printById', layoutId:'shipping-label', fieldValues:{...}, options:{} }

Opens the print dialog. Emits paperstamp:done on afterprint.

paperstamp:register — save a layoutDef into plugin localStorage (no print) 
{ type:'paperstamp:register', layoutDef:{ name:'my-layout', ... } }

layoutDef.name is required. Re-emits paperstamp:ready afterwards.

paperstamp:listLayoutDefs — NEW: fetch every saved layoutDef in one shot 
{ type:'paperstamp:listLayoutDefs' }

Plugin replies with paperstamp:layoutDefs:

{ type:'paperstamp:layoutDefs', layouts:{ id1:{...}, id2:{...} } }
paperstamp:export — export the CURRENT in-memory layout as JSON 
{ type:'paperstamp:export' }

Reply: { type:'paperstamp:exportResult', layoutDef:{...} }

paperstamp:import — replace current in-memory layout with a layoutDef 
{ type:'paperstamp:import', layoutDef:{...} }
paperstamp:openDesigner / setDesignerLayout / closeDesigner 
{ type:'paperstamp:openDesigner' }
{ type:'paperstamp:openDesigner', layoutId:'my-layout' }
{ type:'paperstamp:setDesignerLayout', layoutId:'my-layout' }
{ type:'paperstamp:closeDesigner' }

Lazily loads designer.html + designer.js + designer.css into the embed.

paperstamp:ping — ask the plugin to re-emit ready 
{ type:'paperstamp:ping' }
Inbound log (plugin → host)
